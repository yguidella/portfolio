# 🚀 Sobre o Projeto

O **Portfólio Pessoal** é uma aplicação web moderna, responsiva e interativa desenvolvida para apresentar minhas habilidades como desenvolvedora Full Stack, além de reunir projetos, experiências e formas de contato em uma interface personalizada com identidade visual futurista.

O projeto foi construído utilizando **HTML5, CSS3 e JavaScript**, consumindo dados dinâmicos da API do GitHub para manter automaticamente atualizadas informações do perfil e dos repositórios.

A proposta do projeto é unir:

- Design criativo
- Experiência do usuário
- Responsividade
- Integração com APIs
- Organização de código
- Automatização de conteúdo

---

# ✨ Funcionalidades

## 👾 Interface e Navegação

- Estrutura desenvolvida com HTML semântico
- Layout responsivo para desktop, tablet e mobile
- Menu fixo com navegação suave entre seções
- Estética futurista inspirada em neon/cyberpunk
- Animações suaves em elementos da interface
- Hover interativo entre personagem ilustrada e foto real

---

## 📊 Integração com GitHub API

Consumo dinâmico da API do GitHub para:

- Exibir automaticamente:
  - Quantidade de seguidores
  - Número de repositórios públicos
- Carregar projetos automaticamente
- Atualizar conteúdos sem necessidade de edição manual

---

## 🎠 Carrossel de Projetos

Implementado utilizando **Swiper.js**:

- Slides automáticos
- Navegação por botões
- Paginação dinâmica
- Loop infinito
- Pausa automática ao passar o mouse
- Exibição dinâmica de projetos filtrados por tópicos do GitHub

---

## 📬 Formulário de Contato

- Integração com FormSubmit
- Validação completa no frontend utilizando JavaScript
- Verificação de:
  - Nome
  - E-mail
  - Assunto
  - Mensagem
- Feedback visual de erros
- Página de sucesso após envio

# ⚙️ Funcionalidades JavaScript

## 🔗 Integração com GitHub

O projeto consome dados da API do GitHub utilizando `fetch()`.

### Dados carregados dinamicamente:

- Seguidores
- Quantidade de repositórios
- Projetos do portfólio
- Links automáticos dos repositórios
- Deploys cadastrados no GitHub

---

## 📌 Filtro Inteligente de Projetos

Os projetos exibidos no carrossel são filtrados automaticamente através da topic:

```js
portfolio
```

Isso permite selecionar quais projetos devem aparecer no site diretamente pelo GitHub.
